# PULSE 在真实纵向蛋白质组和代谢组数据中的验证

本研究使用原仓库的 `pulse.model.PulseModel`，在 Su2020、CSIRO、iPOP Seasonal 和 HMP2 上完成患者独立切分的主实验。COVAAR 在完成发布数据的访视连接后单独纳入探索性实验。主实验有 114 个训练检查点，COVAAR 有 30 个。两者共 30 个队列、随机切分及模态方向组合，输出 294 条留出集模型与对照评分。实测证据支持 PULSE 重建部分当前分子谱，并在 iPOP 中利用患者自己的历史。患者内真实变化的预测证据较弱，模型表现随队列、预测方向和比较基线变化。本文将公开测量矩阵的复原、历史增益和跨时间动态分别报告。

## 3. 模型与真实数据接口

模型的访问输入是按顺序排列的模态字典。观测模态先各自编码为高斯分布，历史 GRU 状态经独立编码器生成 Past-State 分布。Jeffrey 散度对齐可见分支和历史分支。融合对可见模态与历史分支的潜在均值等权取平均，解码器从 Visit-State 还原模态，GRU 把融合状态传到下一次访问。使用仓库实际的 recurrent 路径，隐藏维数 64、潜维 16，单个样本最多用最近四次可用历史。外部验证损失为目标观测单元格 MSE，加 0.25 倍上下文重建、0.001 倍 KL 和通常 0.01 倍对齐损失。对齐消融设对齐权重为零，对抗缺失项本轮关闭。AdamW 学习率 0.001，批 8，最多 50 轮，按验证集观测单元格 MSE 早停（耐心 10）。 [PULSE 论文](https://www.nature.com/articles/s43588-026-01026-5)

掩码 0 是可见输入，1 是有真值但人为隐藏的目标，2 是不可见模态。训练评分额外使用逐特征有限值掩码，原始检测到的零保持观测，特征空值在编码输入中填为训练标准化后的 0。原接口没有逐特征掩码通道，模型难以区分这个填充值与真实均值。GRU 按序处理访问，当前接口不接收时间间隔、采样阶段、WHO、疾病或干预，无法在预测时指定一个日历时间。COVAAR 的事件时刻、iPOP 绝对日期和 HMP2 研究周只用于连接和分析。

真实训练输入需要保留三层身份（受试者、访视或采样、各检测编号）、时间原值与单位、干预与阶段、样本体液及处理信息、各平台的原生特征和测量尺度、逐特征观测掩码与整模态掩码。原始值、供货商归一化、训练标准化和临时编码填充值是不同字段或处理阶段。CSIRO 和 Su2020 可以测试阶段依赖，只有数值时间来源明确的 iPOP、HMP2 和 COVAAR 各试验阶段内适合考察定量间隔。不可将不同队列的间隔合并成统一单位。

**已测历史的边际增益。** 对同一测试患者和目标，把有历史的训练臂与独立重训的无历史臂相比，Su2020、CSIRO、HMP2、iPOP 分别有 4/6、4/6、6/6、5/6 组 zMAE 改善，配对中位差分别为 −0.0139、−0.0107、−0.0050、−0.0047。iPOP 蛋白补代谢的三个差值均有利，中位 −0.0200，反向中位 −0.0006。iPOP 蛋白补代谢的短、中、长间隔改善中位分别为 0.0047、0.0208、0.0148 zMAE，对应 ≤30、31–120、>120 天，呈非单调关系。HMP2 按 ≤8、8–12、>12 周分层也未出现稳定的单调梯度。因模型没有接收数值间隔，这些差异是样本条件下的分层结果。

## 5. 真实结果支持的机制判断

当前观测中确实有可预测的跨模态信息，Su2020 和 HMP2 的证据最清楚。给 PULSE 同一患者的既往观测可以改变重建结果，并在 iPOP 的代谢补全和部分未来值预测上改善平均误差。历史替换和历史反序的差异表明，患者基线与历史测量内容是解释增益的主要候选。有序训练在一个方向有附加证据，但无序历史的岭回归在 iPOP 的六组未来预测中均占优。已观察到的对齐差异和未来值误差不足以将潜表示解释为经独立生理量校准的真实状态。结果评估使用发布处理后的组学分子谱，未把单个潜维度对应到病情、干预反应或已验证生理变量。

实际限制包括 Su2020 只有一个可留出的后续访问，CSIRO 阶段与疫苗组重合，HMP2 的零值来源混合，iPOP 发布值含已有填补，COVAAR 只有 16 名独立受试者，P100 定量矩阵需受控访问。试验基于观察到的目标单元格进行人为遮蔽，推断范围为这些可测分子和时间分布。检测阈值以下及从未检测的单元格没有真值供比较。

## 6. 合成研究裁决

建议进行小规模、有已知真值的机制实验，首先区分历史增益来自稳定个体基线，还是来自随干预与真实间隔变化的共享潜状态。真实数据中的身份替换有效、时间反序影响较小及持续值基线难超越给出了具体对照目标。合成数据只承担机制识别。本轮已完成实际队列实验，未启动合成生产或合成训练。

可实施的第一组机制采用连续时间状态空间模型。令个体稳定差异 $b_i\sim N(0,\Sigma_b)$，患者内状态 $z_i(t)$ 为均值回复过程。对每个实际间隔 $\Delta$ 使用转移

$$
z_{i,k+1}=\mu_{s_{i,k}}+e^{-A\Delta}(z_{i,k}-\mu_{s_{i,k}})
          + B_i u_{i,k} + \eta_{i,k},\qquad
\operatorname{Cov}(\eta_{i,k})=\int_0^\Delta e^{-Av}Q e^{-A^\top v}\,dv .
$$

$s_{i,k}$ 是已知仿真疾病或响应阶段，$u_{i,k}$ 是已知干预，$B_i$ 可含可控个体响应差异。特征层按模态分别生成 $v^{(m)}=a^{(m)}+L_b^{(m)}b_i+L_z^{(m)}z_i(t)+L_q^{(m)}q_i^{(m)}(t)+\epsilon^{(m)}$。共享载荷决定跨组学信息，私有因子表示可恢复程度的上限。(g_{mj}(v)) 将潜在读数映射到发布相对尺度，可使用分位数映射产生 iPOP 代谢重尾、Su2020 NPX 有符号信号，并为 HMP2 设置独立的稀疏检测层。对每个特征同时保存无噪声真值、带噪声值和观测标志，检测限、技术缺失、整模态缺失与访视计划分别生成。

标定时对队列分别使用已观测面板的尺度、特征维数、组内和组间秩相关、缺失比例与采样间隔分位数。以 iPOP 的 302／724 特征、1–551 天间隔和 0.132／0.050 的两种相关量作为首个标定目标。Su2020 两阶段和 CSIRO 疫苗阶段用于阶段切换、重尾及高缺失的压力检验。对 HMP2 匹配发布零率，同时以显式情景区分真实低丰度、测量删失和峰处理造成的零。公开数据没有鉴定这些类别的比例，需作为实验参数独立变化。独立受试者计数和访问长度应按实测分布生成，避免用大规模仿真样本量遮蔽真实队列的可辨识性限制。

| 对照 | 控制变量 | 可检验的预期 |
| --- | --- | --- |
| 只有稳定基线 vs 只有共享动态 | 匹配边际和总共享方差，独立切换 $L_b$、$L_z$ | 前者错人敏感、反序不敏感。后者正确时间与相应患者历史都应有增益 |
| 同一访视边际、不同动力学 | 在均值回复、阶段切换、随机排序间改变转移，保持载荷与噪声 | 测试对真实间隔与状态转变的响应，分别比较 GRU、无序历史均值、带 $\Delta$ 的状态空间基线 |
| 固定动力学、改变观测 | 独立调节当前模态、历史目标、检测限、整模态缺失与采样疏密 | 用完全真值区分观测不足、对齐导致信号损失和模型估计误差 |
| 对齐开关与错人历史 | 固定样本和载荷，在稳定与动态情景中重复 | 比较持久值、岭回归、历史均值、真参数 Kalman 估计和 PULSE 的水平、变化误差 |
 
主要评价量是患者内变化误差、干预响应时刻及幅度、预测区间覆盖、相对真参数滤波器的误差。潜因子只在固定旋转或对齐到已知子空间后比较，分别测 $b_i$ 与 $z_i(t)$ 的可恢复度。MEFISTO 的时间高斯过程是拟合真实轨迹和对照平滑因子的依据，scDesign3 提供可借鉴的边际与依赖结构分离。Human1 可约束后续特定通路的反应可行性，当前问题尚缺把反应通量映射到两种血浆测量值所需的动力学与观测参数，首轮以可识别状态空间模型为主。 [MEFISTO](https://doi.org/10.1038/s41592-021-01343-9) · [scDesign3](https://doi.org/10.1038/s41587-023-01772-1) · [Human1](https://doi.org/10.1126/scisignal.aaz1482)

## 7. 复现与证据定位

在 `omics` 分支仓库根目录执行。程序复用现有原始和已准备的文件，只有必要时获取缺失源文件。示例使用 CPU，当前研究的正式结果均由 CPU 生成。归档保留按队列和切分的配置、输入校验值、选中面板、完整指标及对比。工作目录中的原始数据、配对表、逐个体预测和检查点由程序写在数据根目录下。

```bash
python -m pip install -r external_validation/requirements.txt -r external_validation/requirements-structure.txt
ROOT="${PULSE_OMICS_DATA_ROOT:-/mnt/f/datasets/pulse-omics}"
RUNS="$ROOT/results/real_study/reproduce"
python -m external_validation.real_study --data-root "$ROOT" --fetch-missing --device cpu --output "$RUNS/main"
python -m external_validation.real_study --data-root "$ROOT" --datasets covaar --fetch-missing --device cpu --output "$RUNS/covaar"
python -m external_validation.cohort_catalog --data-root "$ROOT" --output "$RUNS/catalog"
python -m external_validation.interpret_study --data-root "$ROOT" --runs "$RUNS/main" "$RUNS/covaar" --output "$RUNS/analysis"
python -m external_validation.reference_baselines --data-root "$ROOT" --runs "$RUNS/main" "$RUNS/covaar" --output "$RUNS/analysis/reference_baselines.csv"
python -m external_validation.csiro_quality --data-root "$ROOT" --runs "$RUNS/main" --output "$RUNS/analysis/csiro_threshold_sensitivity.json"
```

- `catalog/` 是实际数据的文件、工作表、字段及特征目录。 `provenance/` 包含发布地址、文件校验、配对审计和研究运行环境。
- `results/heldout_metrics.csv` 是全部主实验与 COVAAR 评分。 `matched_effects.csv` 是配对差值、各测试样本量及区间。 `reference_baselines.csv` 是匹配的线性对照。 `rank_association.json` 是组内和组间关联及置换参照。
- `results/ipop_diagnostics/` 记录继承的单例批次原训练入口及诊断协议。其错人历史、顺序和尺度结果与主协议独立报告。实验代码位于 `external_validation/diagnostics/`。
- `runs/` 保留源输入校验、训练配置、模型特征面板和训练轨迹，支持审计当前与历史臂的比较。原始测量与个体级结果由复现命令在数据根目录生成。
