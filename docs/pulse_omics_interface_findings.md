# 当前 PULSE 实现的多组学接口事实

代码基准：`omics` 分支 `148aaccb6b846feebee1404331972137d9cea810`。本文来自实际源代码核对及 `restored_omics_sources.md` 的已读取文件；Su2020、HMP2、COVAAR、CSIRO 的原始字段映射尚未完成，本文件不提供这四个队列的假定映射，也不启动合成机制设计。

## 当前输入及信息流

`omics/longitudinal.py::load_sequences` 接收三个已经整理过的 CSV。`subjects.csv` 的 `sample_id, patient_id, visit_order` 是项目适配器的输入名，不是所有原始数据共同拥有的字段。适配器按 `patient_id, visit_order` 排序，将蛋白质组和代谢组向量分别放入每次访问的 `protein`、`metab`。`visit_order` 随后只影响顺序，没有进入模型张量。

`LongitudinalDataset` 返回 `(patient_id, visits, masks)`，不同患者可有不同访问次数。每种模态的掩码为单个整数：0 已观测、1 主动遮盖、2 自然缺失；没有每个组学特征的独立观测掩码，也没有采样时间、体液、批次、干预或检测限参数。

`PULSEModel.forward` 依次执行：取得历史上下文；编码当前已观测模态与历史；计算对齐损失；均值融合；解码每种模态；再用此次融合状态更新 GRU 或 Transformer 历史。当前访问的目标值只在掩码为 0 时参与编码，主动遮盖目标由 `recon_targets` 单独传入重建损失。

历史融合的实际公式为

\[
z_t = \frac{\mu_{\mathrm{past},t}+\sum_{m\in O_t}\mu_{m,t}}{1+|O_t|}.
\]

当当前两模态都未观测时，直接使用历史编码均值。初始历史上下文为零，但通过含偏置项的 `PastStateEncoder` 后，第一访问的历史均值一般不为零，是可学习的初始表示。

## 已读取的原始信息与当前接口

| 真实信息 | 原生位置 | 当前接口状态及含义 |
|---|---|---|
| iPOP 个体身份 | `*_annotation_colData / SubjectID` | 可作为按个体切分的依据，需保留来源前缀；1 条蛋白质组元数据缺失此键 |
| iPOP 原始采样时间 | `Date` 原始 POSIXct 秒数 | 未被当前模型读取；需先解决异常年份，再决定日历与相对时间的保留方式 |
| iPOP 年内日序 | `Time` | 是季节性变量；按此排序会把不同年份混合，不能用它替代真实时间 |
| iPOP 分组和体质指数 | `IRIS, BMI` | 不是模型显式条件；BMI 原来为 factor，须显式转数值 |
| iPOP 蛋白质组特征与处理值 | `Proteomics_df_Data` 302 列 | 模态维度可设为 302，原名保持；在矩阵行身份核实前不输出训练 CSV |
| iPOP 代谢组特征与处理值 | `Metabolomics_df_Data` 724 列 | 模态维度可设为 724；原近邻补齐位置不可恢复，重新遮盖的真值是发布处理值 |
| P100 各轮检测覆盖 | `Demographics / metabolomics.metabolon.*` 等 | 值是观测特征数，不能作为蛋白质或代谢物丰度输入 |
| P100 蛋白质/代谢物标识 | `MOESM30 / Proteomics, Metabolomics` | 可提供特征注释；没有每位参与者的测量矩阵 |
| P100 相关网络 | `MOESM31–34 / Table` | 一行是一条特征相关边，不能映射为一次访问 |

因此，已恢复 iPOP 文件给出了具有纵向结构的双模态数据候选，但当前确认的是原生元数据交集。测量行身份、日期编码及处理尺度尚需源级核实。P100 的公开附件可统计检测覆盖，不能形成当前模型的双组学训练输入。

## 影响后续训练与机制验证的具体实现问题

**真实时间间隔没有进入模型。** `pulse/core/temporal.py` 的 GRU 每个访问更新一次；Transformer 的位置编码只用序列位置。1 天和 551 天的间隔在现有接口中均为一步。当前实现可研究按访问顺序的历史增益，尚不能把误差变化归因于对真实时间尺度的建模。

**特征缺失与整模态缺失的处理不同。** `omics/longitudinal.py` 会将全 NA 向量视为整个模态缺失，遇到部分 NA 则报错；`LongitudinalDataset` 单独使用时，只识别 None 或全 NaN，部分 NaN 会继续作为可用模态输入。`compute_losses` 没有把特征掩码传给重建损失。虽然 `pulse/losses.py::reconstruction_loss` 有可选 `mask` 参数，但其实现先计算含目标值的逐元素误差再乘 mask，NaN 乘 0 仍为 NaN。真正接入特征缺失时，需要先建立有限的编码输入、保留原始观测掩码，并只在已观测且有监督真值的位置计算误差。不能把空值替换为零后丢弃掩码。

**无历史消融需要区分两种操作。** `use_history_in_fusion=False` 确实从当前重建的融合式中去掉历史；有当前模态时，输出只依赖当前编码均值。但 `process_visit` 仍计算当前模态与历史的对齐项，`compute_losses` 仍包含历史 KL 项，时间模块仍更新。该开关研究的是取消历史直接融合；若在训练中以它充当完整无历史模型，历史仍可通过训练损失影响共享参数。需要分别报告训练时移除整个历史分支的模型与同一模型推理时取消历史融合的结果。通用 `Trainer` 当前没有向前传递该开关。

**当前训练遮盖不能直接代表完整未来预测。** 数据集在当前至少有两个已观测模态时，至多主动遮盖一个模态，因此通常保留同次的一种组学。利用它得到的误差对应同次补全或历史条件补全。未来预测要求目标时刻两种真实观测均不作为输入；直接调用模型可在已有历史后添加空查询访问，但通用适配器拒绝两模态皆空的访问，mask=2 的目标也不参加现有重建损失。未来评估需要明确建立预测原点和未来持出目标，不能沿用同次单模态遮盖后更换任务名称。

**返回的 Visit State 是融合均值。** 当前解码器接收均值融合后的状态，没有在该路径中从编码分布采样。编码器 logvar 用于 KL 和对齐项。不能据此把重复确定性解码的散布解释为预测不确定性；若研究生成分布与校准，需要另行定义观测分布与抽样路径。

**现有高斯模拟器的统计命题可直接确定。** `create_synthetic_data` 在每名患者、每次访问、每个模态分别调用独立 `np.random.randn`；仅以随机掩码制造整模态缺失。它没有共享个体变量、跨模态联系或动态依赖。该生成器可检查代码运行，不能作为历史机制有效性的证据。本次未扩充它；新的合成机制按任务要求等待全部真实文件调查完成。

实际整理测量值时，训练/测试需先按原生受试者分割；特征筛选、缩放和任何新补齐参数只用训练人群估计。必须保留原始平台、体液、特征 ID、已知变换及发布版预处理信息，才能确定同次补全、历史条件补全和未来预测分别使用的观测与持出真值。
